# Provider marks

The small, monochrome menu-bar marks identify connected services; they are not the QuotaNest application logo.

- Codex: OpenAI blossom outline from the SVG served by https://openai.com/favicon.svg (retrieved 2026-10-12).
- Claude Code: pixel adaptation of the mascot displayed by the official Claude Code terminal client: https://github.com/anthropics/claude-code.
- Antigravity: official silhouette from https://www.agy.dev/favicon.svg (retrieved 2026-10-12), with background and color effects removed for menu-bar legibility.
